# Pizza Ops Dashboard

피자 프랜차이즈 9개 매장(2020-01~2026-08) 월별 실적을 탐색하는 CEO용 인터랙티브 대시보드입니다.
단일 HTML 파일(`index.html`)이며 서버 없이 브라우저에서 열립니다.

- 데이터: `피자 매장별 실적 데이터.xlsx` (가상 데이터)에서 매장·월 단위 720건을 추출해 파일 안에 포함
- 기능: 기간·매장 필터, 핵심 지표 5개, 성장 분해·마진 구조·매장 지도·히트맵, 시사점 3개, 문제점·개선안 요약
- 한계: 가상 데이터이며 상관은 인과를 뜻하지 않습니다. 추정치(2026-09~10)는 제외했습니다.
